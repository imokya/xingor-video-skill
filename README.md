# xingor-video-skill

一个 AI 视频剪辑技能：交给它一段口播视频、一段旁白音频或一个主题，自动剪成带字幕、动效和音效的成片。采用通用的 [Agent Skills](https://agentskills.io) 格式，可在 Claude Code、WorkBuddy、Codex、Cursor 等支持技能的 AI 助手里使用。

## 支持的风格

- **NEON LAB**（默认）：深色科技感，荧光绿点缀，文字落在人物身后，配演示动画。适合 AI、科技、产品类口播。
- **诗墨国风**：宣纸水墨，竖排诗句、朱砂印章、水墨晕开翻页。适合诗词与文化类内容，也能只用旁白音频出片。
- **文物纪录片**：不需要出镜，文物悬浮在金色展台上，自动找图、配音、配乐。适合文物与历史主题。
- **撞色测评**：不需要出镜，纯配音的 App / AI 工具测评。黑、米白、橙红、电光蓝色块轮换，圆形扩张转场，仿 App 输入框打出真实提问，截图卡片带标注、动态对比表、翻车包袱。出小红书 3:4 和视频号 6:7 两版，附配套封面。

每种风格都带逐字字幕、开头精彩片段（钩子）和音效，支持 16:9、3:4、9:16。

## 用法

在你的 AI 助手里把文件交给它，说想要的效果即可：

```
帮我把 口播.mp4 剪辑一下，加字幕和特效            → NEON LAB
用水墨诗词风格剪辑 口播.mp4                      → 诗墨国风
把 旁白.mp3 做成水墨诗词风格的 3:4 视频            → 诗墨国风（纯旁白）
做一个关于三星堆的文物纪录片                      → 文物纪录片
用这些截图做一期 XX 的纯配音实测视频              → 撞色测评
```

出片后可以接着用一句话修改，比如「标题再大一点」「过渡别用水墨」「再出一版 16:9」。

## 安装

把仓库克隆到 AI 助手的技能目录，例如 Claude Code：

```bash
git clone https://github.com/imokya/xingor-video-skill.git ~/.claude/skills/xingor-video-skill
```

其他助手放进各自的 skills 目录即可（文件夹名保持 `xingor-video-skill`）。

第一次使用时会自动准备运行环境。需要 macOS（用到系统中文字体）；文物纪录片配音需要 MiniMax API Key，撞色测评可用 Fish Audio 或 MiniMax（Key 写在 `.env` 里）。
